## Descripción del sitio

**Destino Cordillera** es un sitio web turístico que tiene como objetivo presentar diferentes alternativas para visitar y disfrutar de la cordillera.

El sitio permite conocer distintos panoramas y actividades, opciones de alojamiento y gastronomía, además de una sección de reserva y contacto.

El proyecto está dividido en las siguientes secciones:

* **Inicio:** presenta información general sobre Destino Cordillera y permite acceder a las principales secciones del sitio.
* **Panoramas:** muestra diferentes actividades y experiencias que se pueden realizar en la cordillera.
* **Alojamiento y Gastronomía:** presenta diferentes alternativas de alojamiento y opciones gastronómicas.
* **Reserva y Contacto:** contiene un formulario para ingresar información de contacto y realizar consultas o solicitudes relacionadas con una reserva.

## Instrucciones para ejecutar o visualizar el sitio

Para visualizar el sitio no es necesario instalar programas adicionales.

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` utilizando un navegador web.
4. Desde la página principal se puede navegar hacia las demás secciones mediante el menú de navegación.

También se puede utilizar **Visual Studio Code** junto con la extensión **Live Server**:

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir el archivo `index.html`.
3. Presionar la opción **Open with Live Server**.
4. El sitio se abrirá automáticamente en el navegador.

El proyecto utiliza Bootstrap mediante CDN, por lo que se recomienda tener conexión a Internet para que sus componentes y estilos se carguen correctamente.

## Tecnologías utilizadas

* **HTML5:** utilizado para crear la estructura y el contenido de las diferentes páginas del sitio.
* **CSS3:** utilizado para agregar estilos personalizados, modificar la apariencia de los elementos y agregar efectos visuales.
* **Bootstrap 5.3.3:** utilizado para facilitar el diseño responsive, la creación de tarjetas, navegación, formularios y distribución de los elementos mediante el sistema de grillas.
* **JavaScript:** utilizado principalmente mediante Bootstrap para permitir el funcionamiento de algunos componentes interactivos, como el menú de navegación responsive.
* **Git y GitHub:** utilizados para el control de versiones y el trabajo colaborativo entre los integrantes del equipo.

## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

* `index.html` → Página principal.
* `panoramas.html` → Página con los diferentes panoramas y actividades.
* `servicios.html` → Página de alojamiento y gastronomía.
* `contacto.html` → Página de reserva y contacto.
